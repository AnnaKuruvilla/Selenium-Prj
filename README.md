# Selenium-Prj

A Java Selenium automation framework to run UI tests using Maven, TestNG, and Extent Reports.

## 🚀 Features

- Selenium WebDriver automation
- TestNG framework integration
- Extent Reports for HTML test reporting
- Jenkins pipeline support
- GitHub integration with webhook triggers

## 📦 Prerequisites

- Java 17+
- Maven 3.9.x
- Git
- IntelliJ IDEA or any Java IDE

## 🛠️ Installation & Setup

```bash
git clone https://github.com/YourUsername/Selenium-Prj.git
cd Selenium-Prj
mvn clean install
